# 国际象棋程序 - JSNgame 示例项目(Deepseek写的)

一个基于 **JSNgame** 游戏引擎开发的国际象棋对战程序，支持玩家执白与强化学习AI（执黑）对战。

## 项目简介

本项目是 JSNgame 游戏开发库的一个完整示例，展示了如何使用该引擎实现：
- 图形化棋盘与棋子渲染
- 鼠标交互（点击移动）
- 国际象棋基本规则（走法、吃子、将军、过路兵、兵升变）
- 集成 JSNgame 内置的 **AI_tree** 模块，实现强化学习驱动的AI对手

> **注意**：由于开发时间紧张，代码中未添加详细注释，但函数和变量命名尽量清晰，希望您能理解。欢迎 fork 并完善！

## 功能特点

- 🎮 **完整对局体验**：玩家执白，AI 执黑，交替走子
- 🧠 **强化学习AI**：基于 `JSNgame.AI_tree.Jai` 类，AI 会根据棋盘状态动态决策，并具备在线学习能力（训练数据保存于 `chess_black.jai`）
- 🎨 **视觉反馈**：选中棋子高亮、可走位高亮（绿色/红色圆点）、吃子震动特效、将军提示
- 🔊 **音效系统**：棋子选中、移动、吃子、将军均有音效
- 🏆 **胜负判定**：王被吃掉或无法解将时游戏结束，并播放胜利动画

## 安装与运行

### 环境要求
- Python 3.7+
- JSNgame 引擎（需安装其依赖）

### 依赖安装
```bash
pip install pygame numpy opencv-python pyaudio
```

同时确保 JSNgame 库已正确放置于 `LIBbase/JSNgame/` 目录下（与 `main.py` 同级）。

### 运行游戏
```bash
python main.py
```

启动后会弹出模式选择窗口（两个按钮功能目前相同，均启动玩家 vs AI 对局），点击即可开始。

## 操作说明

1. **执白方**（玩家）先走。
2. **点击棋子**（棋盘上的图片）会高亮显示该棋子的所有合法走位。
3. **点击合法走位上的格子**即可移动棋子。
4. 轮到 AI 时，程序会自动计算并走子，无需操作。
5. 游戏结束时，失败方的所有棋子会被依次清除，并弹出胜利提示。

## AI 实现说明

- AI 仅控制黑方，使用 `JSNgame.AI_tree.Jai` 强化学习模型。
- 棋盘状态被编码为 64 个格子编码 + 双方棋子数量，共 66 维特征。
- AI 每次走子前会收集当前所有合法动作，调用 `ai.out(state, action_count)` 选择动作索引，执行后通过 `ai.report(state, action, reward)` 反馈奖励。
- 奖励函数综合考虑：吃子价值、将军、解围、中心控制、兵升变。
- 模型文件 `chess_black.jai` 会在对局中自动加载/创建，并在游戏结束时保存学习经验。

> 提示：当前 AI 的训练模式为 `'train'`，每一局都会累积经验。如需纯使用模式可修改 `_init_jai()` 中的参数为 `'use'`。

## 已知局限

- ❌ **未实现王车易位**（国际象棋标准规则之一）
- ❌ **未实现兵升变选择**（兵到达底线后默认未做处理，实际游戏中应允许升变为后、车、马、象）
- ⚠️ **过路兵** 规则已实现，但需手动触发（对方兵跳过时本方兵可斜吃）
- ⚠️ AI 水平有限，需要大量对局训练才能提高强度
