JSNgame 游戏引擎 - 示例代码集

本文件夹包含了基于 JSNgame 引擎开发的多个示例程序和游戏模板，
展示了引擎的主要功能和用法。每个示例都是独立的 Python 脚本，
可以直接运行体验。

📁 示例列表

1. chess/ 或 chess_demo.py
   - 国际象棋对战程序（玩家执白 vs AI执黑）
   - 演示内容：图形渲染、鼠标交互、国际象棋规则、强化学习 AI 集成
   - 运行命令：python main.py （进入 chess 目录后）

（后续可继续添加更多示例，例如：）
2. snake/          - 贪吃蛇游戏（演示事件处理和碰撞检测）
3. platformer/     - 简易平台跳跃游戏（演示长背景滚动和动画）
4. audio_player/   - 音频播放器示例（演示 mixer 音效和音乐播放）
5. ai_pathfinding/ - 寻路算法可视化（演示 Game_AI 类的 A* 和势场法）
...

🚀 快速开始

1. 确保已正确安装 JSNgame 引擎及其依赖（pygame, numpy, opencv-python, pyaudio）
2. 进入任意示例文件夹，按照该示例内的 README 或直接运行主程序
3. 大部分示例需要将 JSNgame 引擎放置在 ../LIBbase/JSNgame/ 或系统 Python 路径中
   如果遇到导入错误，请检查引擎目录是否正确。

📌 注意事项

- 由于开发时间紧张，部分示例代码未添加详细注释，但函数和变量命名尽量清晰，敬请见谅。
- 每个示例的素材（图片、音效）请存放在对应的子文件夹中。
- 示例旨在演示功能，可能未覆盖完整的边界情况，欢迎自行完善。
